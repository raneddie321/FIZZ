# Brand assets

Place the **official RANEDDIE logo** files here (SVG preferred, plus PNG fallbacks), e.g.:

- `raneddie-logo.svg` — full-colour logo for light backgrounds
- `raneddie-logo-dark.svg` — variant for dark backgrounds (optional)

Then set `NEXT_PUBLIC_RANEDDIE_LOGO_SRC=/brand/raneddie-logo.svg` in your environment.
Until then the UI shows a neutral typographic "RANEDDIE" placeholder — no logo has been invented.
